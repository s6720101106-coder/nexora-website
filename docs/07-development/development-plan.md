# Phase 07 — Development Plan

## Implementation sequence
1. Initialize Next.js App Router + TypeScript project and lint/type-check scripts.
2. Add Tailwind and shared design tokens.
3. Build locale-aware layout, header, navigation and footer.
4. Build home, about, services overview, five service pages, portfolio and demo detail template.
5. Build contact, quote and consultation forms with client/server validation.
6. Add server-side submission adapter only after provider and recipient are configured.
7. Add metadata, sitemap, robots, canonical/hreflang and structured data where accurate.
8. Add unit/component/e2e tests and accessibility checks.
9. Configure CI, environment variables, monitoring and deployment after hosting is selected.

## Definition of done
- TypeScript and lint pass.
- All routes render in both locales.
- No fabricated company claims or demo portfolio misrepresentation.
- Forms validate and show accurate success/error states.
- Server submission tested end-to-end before enabling live forms.
- Accessibility, SEO, security and performance checks documented.
- No secrets in repository.
