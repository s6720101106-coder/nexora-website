# Phase 05 — UI Design Direction

## Brand direction
Modern & Minimal; professional, friendly, technology-expert. Tagline: “Innovating Today, Building Tomorrow.” / “สร้างสรรค์นวัตกรรมวันนี้ เพื่ออนาคตที่ดีกว่า”

## Preliminary color tokens
These are working suggestions, not final approved brand assets:
- Navy: `#142B4A`
- White: `#FFFFFF`
- Light neutral: `#E9EEF5`
- Text: deep neutral derived from accessible contrast testing
- Accent: restrained blue accent, to be finalized during visual design

## Typography
Use a clean sans-serif with full Thai/English glyph coverage. Verify font licensing and rendering before release. Establish clear heading/body scale and readable line height.

## Components
Header, locale switcher, primary/secondary buttons, service card, demo project card and label, breadcrumb, process stepper, FAQ accordion (only with approved content), quote form fields, consultation form fields, validation summary, success state, footer.

## Visual rules
Whitespace-led layouts, restrained icon use, consistent spacing/radii, strong hierarchy, no decorative imagery that competes with content. Use real approved logo and project assets when available; until then use neutral placeholders.

## Google Stitch handoff prompt
Design a modern, minimal, bilingual corporate website for NEXORA Technologies, a software and application development company. Use a navy-and-white visual direction, clear typography supporting Thai and English, responsive layouts, accessible contrast, clear service discovery, five distinct service detail templates, clearly labelled demo portfolio work, and high-visibility quote/consultation request CTAs. Do not invent client logos, testimonials, certifications, awards, metrics, or contact details. Include desktop and mobile states for Home, Services overview, Service detail, Portfolio, Contact, Quote form, and Consultation form. Consultation is a request form, not a live booking calendar.
