# Phase 04 — Wireframe Specification

Low-fidelity layout baseline for desktop and mobile. Stitch visual execution is a separate step.

## Global shell
- Header: wordmark/logo placeholder; Home, About, Services dropdown, Portfolio, Contact; TH/EN switch; primary Quote CTA.
- Mobile: compact header and accessible navigation drawer; primary CTA remains discoverable.
- Footer: company summary/tagline, service links, navigation, verified contact channels, privacy link once approved.

## Home
1. Hero: headline, concise value proposition, primary Quote CTA, secondary Services CTA.
2. Service overview: five service cards.
3. Process: Discover → Design → Develop → Test → Deploy → Maintain.
4. Selected demo work with visible demo labels.
5. Why NEXORA: capability statements only; avoid unsupported claims.
6. CTA and contact summary.

## About
Company overview, approach, development process, values. Team facts and credentials are placeholders until verified.

## Services overview
Intro + five service cards + process + enquiry CTA.

## Service detail template (five pages)
Hero/title → problem/outcome → scope/capabilities → process → related demo work → FAQ (only verified answers) → Quote/Consultation CTA.

## Portfolio
Filterable demo project grid; each card carries “Demo / ตัวอย่าง” label. Detail page includes challenge, concept, proposed solution, technology (only if actually used), and disclaimer that it is illustrative.

## Quote form
Contact name, organization (optional), email, phone (optional), service, project summary, budget range (optional/TBD), timeline (optional), preferred contact method, consent/privacy acknowledgement. Do not make budget mandatory.

## Consultation form
Contact name, email, phone (optional), topic, preferred date/time window, preferred contact method, notes, privacy acknowledgement. State clearly that submission is a request, not a confirmed appointment.

## Contact
Verified contact channels only. Do not publish placeholder phone/email as real contact details.

## Responsive/accessibility
Mobile-first, keyboard-operable navigation, visible focus, semantic headings, sufficient contrast, labels and errors for every field, reduced-motion support.
