# Phase 03 — Conversion Funnel

| Stage | Event suggestion | Metric |
|---|---|---|
| Visit | `page_view` | Sessions / visitors |
| Discover | `service_overview_view` | Service discovery rate |
| Evaluate | `service_detail_view`, `demo_project_view` | Detail engagement |
| Intent | `quote_cta_click`, `consultation_cta_click` | CTA click-through |
| Start | `quote_form_start`, `consultation_form_start` | Form start rate |
| Submit | `quote_form_submit`, `consultation_form_submit` | Successful submissions |

Dimensions: locale, page type, service category, device category, traffic source where consent permits.

Never send names, email, phone, project description, or form contents to analytics. Numeric KPI targets remain TBD until baseline data and business goals are approved.
