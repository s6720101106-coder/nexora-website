# Handoff — NEXORA Technologies

## Product
Bilingual corporate website for a technology company offering software and application development to individuals, SMEs, large organizations, and government agencies in Thailand and internationally.

## Main conversion paths
1. Service discovery → service detail → request a quote.
2. Service discovery → consultation request.
3. Portfolio demo → related service → enquiry.
4. Language switch between `/th/` and `/en/`.

## Pages
Home, About, Services, five service detail pages, Portfolio, Demo Project detail, Contact, Request a Quote, Consultation. Legal/privacy pages are required before production form launch and must contain reviewed company-specific content.

## Technical baseline
Next.js + TypeScript + Tailwind CSS; shadcn/ui where appropriate; Git/GitHub; Google Stitch for visual design; OpenCode for coding agent; Markdown documentation.

## Pending real-world inputs
Legal company name/registration, address, telephone, email, LINE Official URL, WhatsApp URL, domain, logo assets, actual staff/process, privacy policy, data retention, approved credentials, real client work, quote recipient, consultation handling, hosting, analytics, budget and schedule.

## Release restriction
Do not publish live forms until a secure server-side submission destination, spam controls, privacy notice, consent approach, retention policy, and recipient are configured and verified.
